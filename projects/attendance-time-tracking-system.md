# Attendance and Time-Tracking System

Public presentation page for the workforce tracking solution highlighted in my resume.

## Project Summary

This project was a web-based attendance and time-tracking solution used to monitor employee in-time, out-time, break activity, and total worked hours. I contributed as a Software Developer across design, coding, testing, maintenance, client handling, and support, with experience in .NET Core and AngularJS delivery.

# Next ETS

Public presentation page for the enterprise workflow platform highlighted in my resume.

## Project Summary

Next ETS is a web-based enterprise platform built around a multi-tenant operational model with distinct access paths for super admins, vendors, vendor admins, and customers. I contributed as a Team Lead, helping deliver the platform architecture, role-driven workflows, and tenant-aware data handling. Across my Bthinq projects, I worked with .NET Core, Angular, Ionic, and ReactJS.

## My Role

- Company: Bthinq Information Systems Private Limited
- Role: Team Lead
- Duration: 01/2022 - 07/2024
- Location: Chennai, India

## Feature List

- Web-based enterprise workflow platform
- Role-based access for super admin, vendor, vendor admin, and customer users
- Multi-tenant operating model
- Separate data management for vendor and customer environments
- Support for employee and customer record handling

## Tech Used

- C# .NET Core
- Angular 8
- Ionic
- ReactJS
- REST APIs
- Entity Framework
- SQL Server
